- **Vert 7:** Raider King’s [scaffold map](https://raiderking.com/wp-content/uploads/2025/10/Pokemon-Legends-Z-A-Colorful-Screws-Locations-16-1024x576.jpg) and [roof map](https://raiderking.com/wp-content/uploads/2025/10/Pokemon-Legends-Z-A-Colorful-Screws-Locations-17-1024x576.jpg) show different player locations, not pickup centres. An exploratory building/canal patch screen (no ring in either fit) puts the scaffold reticle ~4.34 native px from the lower row and the roof reticle ~3.25 px from the higher row. Only two/three withheld patch correspondences respectively were within 3 px, while other patches had mismatches. This is a rough discrimination between the two locations, **not** an approved image registration or positional error estimate. Altissimo also describes separate floors and the roof route through the Holovator unlocked by Side Mission 040.
