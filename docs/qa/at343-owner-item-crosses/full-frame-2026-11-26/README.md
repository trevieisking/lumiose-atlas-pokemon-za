The source game map stays north-up. Use repeated permanent corners and road or canal geometry first, with faint crosses as secondary checks only within an already checked overlap. Crosses without item balls rule out treating an X as a pickup marker. Match across views using reserved check points and record errors and uncertainty before approving any use beyond local alignment. Icons, player rings, clipped edges and oblique capture are not geometric truth. These four pictures improve overlapping coverage; they do not by themselves certify every sector edge, every floor, or any item location.
