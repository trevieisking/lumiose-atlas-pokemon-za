## Source authority / how to use the findings

1. The Pokémon Company's [official gameplay site](https://legends.pokemon.com/en-us/gameplay) supports overarching battle and Mega Evolution mechanics but **not mission-specific NPC rosters/reward amounts**. Nintendo's [official Z-A Link Play support](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68627/) confirms the matching 8-digit-code Link Trade interface for a separate future guide, **not that trading is needed for all Pokémon evolves**.
2. The [Bulbapedia side mission table](https://bulbapedia.bulbagarden.net/wiki/Mission_(Legends:_Z-A)) transcribes objectives, requesters, unlocks and item quantities but is community-maintained. Cross-check against [Serebii individual mission pages](https://www.serebii.net/legendsz-a/sidemissions.shtml), [Thonky's indexed walkthrough](https://www.thonky.com/pokemon-legends-z-a/list-of-side-missions) and the [Bulbapedia #061–080 detailed walkthrough](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Legends:_Z-A/Side_Missions_61-80). Explicitly hold conflicting quantities, precise sector names and unlock timestamps pending game screenshots.
3. **Code integrity:** All **203** `side-quest` article IDs in this exact branch are distinct. Each #061–080 has exactly one corresponding `data-side-check` checkbox and a `side-missions.html#quest-N` source link. All 20 item `Reward:` labels omit full monetary payout and/or quantity, despite keeping reward names. No assertion that the **standalone destination page** contains more complete material: it is an unrecovered placeholder in this reconstruction.
4. **Status terms:** **Confirmed B text issue** = current B text is misleading or incomplete compared with corroborated external evidence; **disputed** = do not silently change without original UI/game recording; **preserve** = current core is sound. These are not claims about live A.
