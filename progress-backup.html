02 / THE ORIGINAL GUIDE

Bring checkmarks from the old site

The old ChatGPT Site has a different web address. This new site cannot read its progress directly. This optional bookmark reads the checked boxes on the original page and downloads a compatible file, without changing the original website.

Open the original Lumiose Atlas guide using the same device and browser where your progress was saved.

  1. Copy the bookmark code below. Add a browser bookmark named Export Atlas Progress and edit that bookmark's URL to the copied code.
  2. Return to the original guide and wait until its checklists have loaded. Run the bookmark while that page is open. On some Android browsers, search your bookmark name in the address bar and select it.
  3. Check Downloads for the new JSON file. Return to this page and choose it in Step 03.
Show code and troubleshooting

The exporter reads only the original page's five checkbox categories. It does not request passwords, read cookies, query Supabase or send any information over the internet.

Some browsers block bookmarklets. If it fails, keep the old site and its browser data intact. We will provide a simpler built-in export when that Site editor is accessible.

Compatibility note: This workaround is based on the saved original website's checkbox structure. We have not verified the exporter in the locked original Site editor. Check your downloaded file before changing guides.

Your progress is yours

Will the original site be changed?

No. The original URL, database and existing progress are untouched. The old-page exporter only reads checked boxes.

Can I transfer between phones?

Yes. Export your JSON file on the device with your progress, move it privately to your other device, then import it on the new guide. There is no automatic browser-to-browser sync.

What if I already ticked some items here?

Your existing checked items stay checked. Only completed items from the backup are added. There is no destructive Replace button.

Does this import player ratings and feedback?

No. Those are separate Supabase records. This is only for gameplay checklists.
