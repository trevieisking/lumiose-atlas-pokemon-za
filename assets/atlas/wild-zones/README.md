# Wild Zone owner map photographs

This is the original owner-provided Wild Zone source image library for Lumiose Atlas. Keep the full photographs, not AI-generated replacements. The consistent filenames are `wild-zone-NN-overview.png` (map with Pokédex completion/species card) and `wild-zone-NN-closeup.png` (larger view of the zone geometry). Each incoming batch of ten covers five zones; record its original filenames, byte counts, dimensions, SHA-256 and Git blob hashes in a batch manifest.
